---

🔎 What I learned

Browser Security

Browsers are our main entry point to the internet. If we don’t keep them secure, we are basically exposing ourselves to
hackers and malware. Even though modern browsers come with security features like safe browsing, HTTPS warnings, and updates, 
we can still get into trouble if we install shady stuff.

Extensions

Extensions are like small add-ons that make our life easier (ad blockers, dark mode, screenshot tools, etc.), but they can 
also be dangerous. Some malicious ones can:

Track what sites we visit.

Inject ads or pop-ups.

Steal login info or personal data.


Permissions

When we install an extension, it usually asks for permissions. Some are normal, but others are red flags, for example:

“Read and change all your data on websites you visit” → full access to browsing.

Clipboard access → can steal copied passwords.

Run in the background → could spy all the time.


Browser Malware

Malware can come into browsers through:

Fake/malicious extensions.

Browser hijackers (changing search engines/homepage).

Phishing pages that steal passwords.

Malvertising (malicious ads).


Security Best Practices

Some simple steps to stay safe:

Only install extensions from trusted sources.

Always check permissions before adding an extension.

Remove extensions you don’t use anymore.

Keep your browser and extensions updated.

Use a password manager instead of saving passwords in the browser.

Clear cookies and history often.
